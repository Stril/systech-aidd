## 🧪 Тест-кейсы

### Тест 1: Команда /start

**Действие:**
```
Отправить боту: /start
```

**Ожидаемый результат:**
- Бот отвечает приветственным сообщением
- Пользователь создается в базе данных
- Логи показывают: `user_command|command=start`

---

### Тест 2: Команда /help

**Действие:**
```
Отправить боту: /help
```

**Ожидаемый результат:**
- Бот отвечает справочным сообщением со списком команд
- Логи показывают: `user_command|command=help`

---

### Тест 3: Команда /role

```

```

**Ожидаемый результат:**

### Тест 4: Текстовое сообщение (с LLM)

**Действие:**
```
Отправить боту: Привет! Как дела?
```

**Ожидаемый результат:**
- Бот отправляет "⏳ Обрабатываю ваш запрос..."
- Затем отправляет ответ от LLM
- Сообщение сохраняется в контексте диалога
- Логи показывают:
  - `message_received|user_id=XXX`
  - `llm_request|user_id=XXX`
  - `llm_response|user_id=XXX`

---

### Тест 5: Команда /reset

**Действие:**
```
Отправить боту: /reset
```

**Ожидаемый результат:**
- Бот отвечает: "История диалога очищена"
- Контекст диалога удаляется
- Следующее сообщение начинает новый диалог
- Логи показывают: `conversation_reset|user_id=XXX`

---

### Тест 6: Длинный диалог

**Действие:**
```
1. Отправить: Расскажи про Python
2. Отправить: А что такое list comprehension?
3. Отправить: Приведи пример
4. Отправить: Спасибо!
```

**Ожидаемый результат:**
- Бот отвечает на каждое сообщение
- Контекст сохраняется между сообщениями
- LLM "помнит" предыдущие сообщения
- В базе создается диалог с несколькими сообщениями

---

### Тест 7: Проверка контекста

**Действие:**
```
1. Отправить: Меня зовут Александр
2. Отправить: Как меня зовут?
```

**Ожидаемый результат:**
- Бот во втором ответе упоминает имя "Александр"
- Это подтверждает, что контекст работает

## 📊 Мониторинг тестирования

### Просмотр логов в реальном времени

```bash
# Все логи
docker-compose logs -f

# Только бот
docker-compose logs -f bot

# Последние 50 строк
docker-compose logs --tail=50 bot
```

### Проверка базы данных

После тестирования проверьте:
```bash
# Подключиться к контейнеру
docker-compose exec bot bash

# Проверить БД
sqlite3 /app/data/bot.db "SELECT COUNT(*) FROM users;"
sqlite3 /app/data/bot.db "SELECT COUNT(*) FROM messages;"
sqlite3 /app/data/bot.db "SELECT COUNT(*) FROM conversations;"
```

### Проверка Dashboard

1. Откройте: http://localhost:3000/dashboard
2. Обновите страницу (F5)
3. Проверьте, что:
   - Счетчики обновились
   - График активности показывает новые сообщения
   - Список диалогов содержит ваши тестовые диалоги
   - Top Users включает вашего тестового пользователя

## 🐛 Возможные проблемы

### Бот не отвечает

**Причина:** Не настроен TELEGRAM_BOT_TOKEN или OPENAI_API_KEY

**Решение:**
```bash
# Проверить .env
cat .env

# Перезапустить контейнеры
docker-compose restart bot
```

### Ошибка "Request timeout"

**Причина:** OpenAI/OpenRouter API медленно отвечает

**Решение:**
- Это нормально, бот обработает запрос
- Проверьте логи: `docker-compose logs bot`

### Бот отвечает ошибкой

**Причина:** Проблема с LLM API (лимиты, ошибка API)

**Решение:**
- Проверьте баланс OpenRouter
- Проверьте OPENAI_API_KEY валиден
- Посмотрите подробности в логах
