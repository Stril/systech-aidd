# 🗺️ Quick Tour

Обзор возможностей бота за 15 минут.

## Доступные команды

### `/start` - Начать работу
Регистрирует пользователя и выводит приветствие.

```
Вы: /start

Бот:
Привет! 👋
Я LLM-ассистент, готовый помочь с различными задачами.
Просто напиши мне сообщение, и я отвечу.

Доступные команды:
/help - Справка по командам
/role - Моя текущая роль
/reset - Очистить историю диалога
```

### `/help` - Справка
Показывает список команд и возможностей.

### `/role` - Текущая роль
Показывает системный промпт - роль ассистента.

```
Вы: /role

Бот:
🎭 Моя текущая роль:

Ты - универсальный помощник...
```

### `/reset` - Очистка истории
Удаляет весь контекст диалога, начинает с чистого листа.

```
Вы: /reset

Бот: История диалога очищена ✨
```

## Диалог с контекстом

Бот помнит последние **10 сообщений** диалога.

**Пример:**

```
Вы: Привет! Меня зовут Алекс.

Бот: Приятно познакомиться, Алекс! Чем могу помочь?

Вы: Как меня зовут?

Бот: Тебя зовут Алекс, ты представился в начале нашего разговора.
```

**Ограничения:**
- Контекст хранится **в памяти** (теряется при рестарте)
- Максимум **10 сообщений** в истории
- Используйте `/reset` для очистки

## Смена роли ассистента

Роль определяется файлом `system_prompt.txt` в корне проекта.

### Текущая роль (по умолчанию)
Универсальный помощник для различных задач.

### Как изменить роль

**Вариант 1: Использовать готовый пример**

```bash
# Технический консультант
cp examples/prompts/technical_consultant.txt system_prompt.txt

# Образовательный ассистент
cp examples/prompts/educational_assistant.txt system_prompt.txt

# Креативный помощник
cp examples/prompts/creative_helper.txt system_prompt.txt
```

**Вариант 2: Создать свою роль**

Отредактируйте `system_prompt.txt`:
```
Ты - специалист по Python.

Твой профиль:
- Эксперт в Python 3.11+
- Знаешь best practices
- Помогаешь с отладкой

Твои задачи:
- Отвечать на вопросы по Python
- Делать code review
- Предлагать улучшения кода
```

**После изменения:**
```bash
# Перезапустите бота
# Ctrl+C для остановки
make run
```

**Проверка:**
```
Вы: /role

Бот: 🎭 Моя текущая роль: Ты - специалист по Python...
```

## Логи

Бот записывает логи в `logs/YYYY-MM-DD.log`.

**Просмотр логов:**
```bash
# Последние логи
tail -f logs/2025-10-16.log

# Поиск ошибок
grep "ERROR" logs/2025-10-16.log
```

**Формат логов:**
```
2025-10-16 10:30:00|src.message_handler|INFO|user_message|user_id=123|chat_id=456
2025-10-16 10:30:01|src.openai_client|INFO|llm_request|model=gpt-3.5-turbo
2025-10-16 10:30:03|src.openai_client|INFO|llm_response|response_time=2.1
```

## Обработка ошибок

Бот gracefully обрабатывает ошибки LLM API:

**Таймаут:**
```
Бот: Извините, запрос к LLM занял слишком много времени ⏱️
Попробуйте повторить позже.
```

**Rate limit:**
```
Бот: Превышен лимит запросов к LLM API 🚦
Подождите немного и попробуйте снова.
```

**Ошибка API:**
```
Бот: Произошла ошибка при обращении к LLM API ⚠️
Попробуйте позже или обратитесь к администратору.
```

Все ошибки логируются в файл для анализа.

## Метрики

Бот отслеживает метрики в памяти:
- Количество пользователей
- Количество сообщений

**В логах:**
```
application|metrics|users=5|messages=42
```

## Ограничения текущей версии

⚠️ **In-memory storage:**
- Все данные хранятся в памяти
- При рестарте бота данные теряются
- История диалогов не сохраняется между запусками

⚠️ **Нет персистентности:**
- Нет базы данных
- Нет сохранения пользователей

⚠️ **Нет rate limiting:**
- Нет защиты от спама
- Нет ограничений на количество запросов
