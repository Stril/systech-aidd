# 📚 Руководства по проекту

Система гайдов для быстрого онбординга и понимания проекта.

## 🎯 Навигация по гайдам

### Уровень 1: Быстрый старт (15 минут)

1. **[Getting Started](01-getting-started.md)** - Установка и первый запуск
   - Prerequisites
   - Установка зависимостей
   - Настройка .env
   - Запуск бота

2. **[Quick Tour](02-quick-tour.md)** - Обзор возможностей
   - Команды бота
   - Примеры использования
   - Смена роли
   - Базовое тестирование

### Уровень 2: Понимание архитектуры (1 час)

3. **[Architecture Overview](03-architecture-overview.md)** - Архитектура проекта
   - Принципы и паттерны
   - Компоненты системы
   - Flow обработки сообщений
   - Dependency injection

4. **[Codebase Tour](04-codebase-tour.md)** - Тур по кодовой базе
   - Структура проекта
   - Описание модулей
   - Где что искать

5. **[Visual Architecture](05-visual-architecture.md)** - Визуализация архитектуры
   - Компонентные диаграммы
   - Потоки данных
   - Диаграммы последовательности
   - Машины состояний

### Уровень 3: Процессы разработки (2 часа)

8. **[Development Workflow](08-development-workflow.md)** - Процесс разработки
   - TDD подход
   - Добавление фичи
   - Рефакторинг
   - Git workflow

9. **[Testing Guide](09-testing-guide.md)** - Гайд по тестированию
   - Типы тестов
   - Запуск тестов
   - Написание тестов
   - Coverage

## 🚀 Рекомендуемый путь

**Для новых разработчиков:**
1. Прочитать [Getting Started](01-getting-started.md) → запустить бота
2. Прочитать [Quick Tour](02-quick-tour.md) → попробовать команды
3. Прочитать [Architecture Overview](03-architecture-overview.md) → понять структуру
4. Прочитать [Codebase Tour](04-codebase-tour.md) → изучить код
5. Изучить [Visual Architecture](05-visual-architecture.md) → визуализировать систему
6. Начать разработку с [Development Workflow](08-development-workflow.md)

**Для code review:**
1. [Architecture Overview](03-architecture-overview.md) - понять принципы
2. [Visual Architecture](05-visual-architecture.md) - визуализация системы
3. [Development Workflow](08-development-workflow.md) - понять процесс
4. [Testing Guide](09-testing-guide.md) - проверить тесты
