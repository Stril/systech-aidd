**Проблема:**
Файл `.env.example` упоминается в документации (README.md:141, Makefile:65), но отсутствует в проекте.

**Важность:** Низкая (не влияет на работу, но удобно для новых пользователей)

**Решение:**
Создать файл `.env.example` в корне:

```bash

# OpenRouter/LLM Configuration
OPENAI_API_KEY=your_openrouter_api_key_here
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=openai/gpt-oss-20b:free

# System Configuration
LOG_LEVEL=INFO
SYSTEM_PROMPT_FILE=system_prompt.txt
```
