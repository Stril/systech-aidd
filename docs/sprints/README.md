# Sprint Documentation

Эта папка содержит документацию по всем завершенным спринтам проекта, разделенную по категориям.

## Структура

### 📁 [backend/](backend/)
**Backend/API спринты** - разработка API и серверной части

- `SPRINT1_IMPLEMENTATION.md` - Реализация Mock API для дашборда статистики
- `SPRINT1_VERIFICATION.md` - Проверка и тестирование Mock API

### 📁 [frontend/](frontend/)
**Frontend спринты** - разработка пользовательского интерфейса

- `SPRINT2_IMPLEMENTATION.md` - Инициализация Frontend проекта (Next.js, TypeScript, shadcn/ui)
- `SPRINT4_SUMMARY.md` - Реализация AI Chat компонента
- `SPRINT_FE-SP-4_SUMMARY.md` - Переход на Real API (замена Mock на SQLite)
- `SPRINT_FE-SP-6_SUMMARY.md` - Авторизация пользователя в ИИ-чате
- `SPRINT_FE-SP-7_SUMMARY.md` - Хранение диалогов ИИ-чата

### 📁 [devops/](devops/)
**DevOps спринты** - контейнеризация, CI/CD, инфраструктура

- `SPRINT_D-SP-1_SUMMARY.md` - Basic Docker Setup (контейнеризация всех сервисов)
- `SPRINT_D-SP-1_VERIFICATION.md` - Проверка и тестирование Docker setup

## Хронология спринтов

1. **Sprint 1** (Backend) - Mock API для дашборда статистики
2. **Sprint 2** (Frontend) - Инициализация Frontend проекта
3. **Sprint 4** (Frontend) - AI Chat компонент
4. **Sprint FE-SP-4** (Frontend) - Переход на Real API
5. **Sprint FE-SP-6** (Frontend) - Авторизация пользователя
6. **Sprint FE-SP-7** (Frontend) - Хранение диалогов
7. **Sprint D-SP-1** (DevOps) - Docker контейнеризация
